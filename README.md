# GT Travels — Northeast India Specialists

A luxury, modern, mobile-first responsive tourism website showcasing the unexplored wonders of Northeast India across all 8 Sister States: Meghalaya, Assam, Arunachal Pradesh, Sikkim, Nagaland, Manipur, Mizoram, and Tripura.

---

## 🌟 Highlights & Features

- **8 Northeast States Covered**: Complete destination galleries, authentic cultural highlights, curated itineraries, and top sightseeing attractions.
- **Meghalaya Tour Circuits & Cab Services**: 4 dedicated road trip circuits (Shillong Local, Cherrapunji / Sohra, Dawki & Shnongpdeng, Jaintia Hills) with vehicle options (Dzire, Baleno, Fronx, Innova, Crysta, Ertiga).
- **Mobile-First & Fully Responsive**: Tested and optimized across 320px, 375px, 390px, 430px, 768px, 1024px, and 1280px+ desktop viewports with zero horizontal overflow.
- **Glassmorphic Hero Search Bar**: Frosted-glass search capsule with instant query filtering connecting directly to the destinations catalog.
- **Direct WhatsApp & Phone Booking**: 1-tap booking buttons and contact forms directly connecting travelers with tour operators.
- **No Visible Pricing**: Strictly inquiry-based bespoke custom quotes.

## 🚀 Quick Start (Local Setup)

Because this website is built with vanilla modern HTML5, CSS3, and JavaScript, no build step or package installation is required.

### Run Locally with Python:
```bash
# Python 3
python -m http.server 8080
```
Open your browser at: `http://localhost:8080`

### Run Locally with Node / NPX:
```bash
npx serve .
```
